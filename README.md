# 考研番茄钟 · 学习看板

这是一个面向考研复习场景的网页版番茄钟与学习看板，帮助你在学习过程中进行计时、记录、统计和复盘。

项目还包含一个位于 [`server/`](server/) 的 Python 服务器版，支持账号登录、云端数据、跨设备计时和好友在线状态；部署说明见 [`server/README.md`](server/README.md)。

## 项目简介

项目包含两个入口：

- [考研番茄钟-学习看板.html](考研番茄钟-学习看板.html)：主界面，提供完整的计时、统计、日历和项目管理体验。
- [考研番茄钟-单文件版.html](考研番茄钟-单文件版.html)：单文件版本，适合快速体验或离线演示。
- [index.html](index.html)：入口跳转页面，会自动跳转到学习看板页面。

## 主要功能

- 番茄钟计时：支持正计时和倒计时模式。
- 学习项目管理：可新增、归档、切换复习科目或项目。
- 学习数据记录：自动把计时结果累计到每日学习数据中。
- 统计分析：查看今日/本周学习时长、趋势图和分项统计。
- 日历视图：查看学习记录和日期分布。
- 备份与恢复：支持导出/导入学习数据备份，提供自动安全副本。
- 本地存储：数据保存在浏览器本地，便于离线使用。

## 使用方法

1. 直接在浏览器中打开 [考研番茄钟-学习看板.html](考研番茄钟-学习看板.html)。
2. 进入“计时”页面开始学习计时。
3. 在“首页”中查看今日目标和学习状态。
4. 在“统计”页面查看学习时长和图表。
5. 在“日历”页面查看学习记录分布。

> 该项目不依赖构建工具，适合直接打开使用。

## 数据说明

项目使用浏览器的 localStorage 保存以下内容：

- 学习时长记录
- 会话明细
- 里程碑信息
- 项目配置
- 计时状态

如果你需要迁移数据，可以使用页面中的备份导出与恢复功能。

## 开发说明

### 运行测试

项目自带简单的 Node 测试脚本。

```bash
node tests/storage.test.js
node tests/timer.test.js
```

浏览器流程测试需要一个可用的无界面浏览器实例，示例：

```bash
node tests/browser.test.js
```

## 说明

这是一个适合个人考研复习管理的轻量级前端项目，重点在于简洁体验和高可用的学习记录能力。你可以根据自己的需要继续扩展为移动端适配、提醒音效、任务日历或云端同步版本。
